# cruise-network-noc-dashboard
A Ship network operations center dashboard simulation

## Overview
A Simulated Network Operation Center ( NOC ) dashboard for cruise ship's IT Infrastructure. It tracks deck-by-deck device status, crew/personal status, live tickets, and includes incident detection system with manual crew assignment.

## TECH STACK
-Python
-HTML

## Features
-Deck by deck device status monitoring
-Personal/crew status tracking
-Live ticket system
-Incident detection with crew assignment modal
